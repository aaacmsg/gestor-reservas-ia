Cómo se calcula la previsión

  • Se cuentan las horas reservadas por semana en las últimas 12 semanas completas.
  • La previsión usa una media móvil de {{ ventana }} semanas: cada semana futura es el promedio de las {{ ventana }} semanas anteriores, y ese resultado se usa para calcular la siguiente.
  • La ocupación es el porcentaje de las 84 horas semanales disponibles (7 días de 09:00 a 21:00).
  • Si la ocupación prevista es de {{ umbral_alto }}% o más se sugiere subir el precio un {{ ajuste }}%. Si es de {{ umbral_bajo }}% o menos se sugiere bajarlo un {{ ajuste }}%.
  • Es solo una sugerencia: el precio no cambia solo, se edita desde el admin.
